# 🏪 Maxikiosco Simulat-AR

> A first-person simulation game set in Buenos Aires, Argentina.  
> Developed as part of the Integration Seminar at UADE (2024).

---

## 🎮 About the Game

**Maxikiosco Simulat-AR** is a relaxing first-person simulation game inspired by Argentine
convenience stores (*kioscos*). Players manage their own stores near the iconic Obelisk,
handling everything from restocking shelves to negotiating prices with customers.

The game aims to represent a piece of Argentine urban culture rarely explored in video games,
combining immersive environments, local sounds, and authentic NPC interactions.

---

## 🛒 Core Mechanics

| Mechanic | Description |
|----------|-------------|
| 🛒 **Buying & Selling** | Manage transactions with customers in real time |
| 📦 **Restocking** | Keep shelves full with over 130 products |
| 🧹 **Maintenance** | Keep your store clean and running |
| 💰 **Price Management** | Set and adjust prices to maximize profit |
| 🎨 **Customization** | Personalize your kiosk's look and feel |

---

## 🌆 Setting

Located near **El Obelisco**, the heart of Buenos Aires.  
The environment, soundtrack, and NPC behavior are all designed to reflect authentic
Argentine street culture.
